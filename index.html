Análisis de red eléctrica

Analiza una red de subestaciones

Sube el dataset con las subestaciones y las líneas de transmisión. Obtendrás tres resultados:

Costo mínimo de instalación
La red más barata que mantiene todas las subestaciones conectadas. Se calcula con Kruskal.
Flujo máximo
Cuánta energía puede viajar entre dos subestaciones. Se calcula con Ford-Fulkerson.
Subestaciones críticas
Las que dejan secciones de la red incomunicadas si fallan. Se detectan con DFS.

Sube tu dataset

Elige el archivo con las subestaciones y las líneas que las conectan.

Acepta .json y .csv con al menos 1500 subestaciones.
