Ayuda y accesibilidad

Accesibilidad

Cómo usarlo

  1. Sube un JSON con nodos y aristas o usa la red de ejemplo
  2. Usa coordenadas WGS 84 en orden longitud, latitud
  3. Elige Kruskal o Prim para calcular la longitud mínima de cableado, o BFS para revisar la conectividad

Qué significa cada color

  • Nodo
  • Tramo documentado
  • Conexión candidata
  • Conexión seleccionada por Kruskal o Prim
